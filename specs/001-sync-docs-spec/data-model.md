## Entities

### 1) Run

Represents a single invocation that performs generation (non-help).

**Fields (conceptual)**:

- `run_id`: Unique, lexicographically sortable identifier (ULID), auto-generated by SQLite `ulid()` function from `sqlite-ulid` extension using `DEFAULT (ulid())` in the database schema.
- `created_at`: Start time.
- `completed_at`: End time (nullable).
- `status`: One of running/complete/failed/interrupted/partial.
- `source_root`: Source directory root.
- `target_root`: Target directory root.
- `output_type`: Requested output format.
- `dry_run`: Boolean.
- `fingerprint`: Fingerprint representing the relevant input+config state for finalize/resume validation.
  - Format: Combined fingerprint of all input file fingerprints plus configuration state (output type, source/target paths, ignore rules content).
  - Used to validate that inputs and configuration are unchanged before allowing finalize or resume operations.
- `counters`: Total/processed/skipped/failed.

### 2) Generated Artifact

Represents a generated output artifact linked to an input source and run.

**Fields (conceptual)**:

- `artifact_id`: Unique identifier.
- `run_id`: Owning run.
- `source_path`: Input file path.
- `output_path`: Generated artifact path (under `${TARGET_DIR}/.pndcgn/${TYPE}-${RUN_ID}/`).
- `input_fingerprint`: Fingerprint for the input (format: `{size}:{mtime}:{sha256_first_64KB}`).
- `output_fingerprint`: Fingerprint representing the full set of output artifacts produced for this source in this run (changes if any output artifact changes).
  - Format: `{total_size}:{artifact_count}:{sha256_of_all_content}` where total_size is sum of all artifact sizes in bytes, artifact_count is number of artifacts, and sha256_of_all_content is SHA256 hash of concatenated artifact content (sorted by artifact path for determinism).
- `generated_at`: Timestamp.
- `size_bytes`: Size of output (optional for reporting).

### 3) Ignore Configuration

Represents the ignore rules applied during discovery and traversal.

**Fields (conceptual)**:

- `source_root`: Where `.pndcgnignore` is discovered.
- `ignore_file_path`: Path to `.pndcgnignore`.
- `seeded_from_gitignore`: Boolean.
- `seed_strategy`: "gitignore-stacking" or "built-in-default".

## Relationships

- A **Run** has many **Generated Artifacts**.
- An **Ignore Configuration** applies to discovery within a given **source_root**.

## Invariants

- Run output directory for a non-help run is deterministic by `{target_root, output_type, run_id}`.
- `.pndcgnignore` is created at most once automatically (seed-once), then only changed via explicit reseed action.
- `output_fingerprint` MUST change whenever any produced output artifact changes (content, set membership, or naming/path changes).
