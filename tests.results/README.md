# Test Results Directory

This directory contains test execution results and evidence for the pndcgn project.

**Location**: Repository root (`tests.results/`)

## Structure

```text
tests.results/
├── logs/              # Temporary log files (automatically removed after processing)
│   └── {test-name}-{YYYYMMDD-HHMMSS}.log
├── reports/           # Formatted markdown test reports
│   └── {test-name}-{YYYYMMDD-HHMMSS}.md
├── coverage/          # Code coverage HTML reports (generated by ShellSpec with kcov)
│   └── index.html
├── generate-reports.sh  # Script to generate reports from logs
└── README.md          # This file
```

- **Logs** (`logs/`): Temporary raw test execution output from ShellSpec
  - **Naming Convention**: `{test-file-name}-{YYYYMMDD-HHMMSS}.log`
  - **Note**: Automatically removed after report generation (full log is included in each report)
- **Reports** (`reports/`): Formatted markdown test reports with summaries and full logs
  - **Naming Convention**: `{test-file-name}-{YYYYMMDD-HHMMSS}.md`
- **Coverage Reports** (`coverage/`): Code coverage HTML reports generated by ShellSpec with kcov
  - **Location**: `tests.results/coverage/index.html`
  - **Generated**: When running `shellspec --kcov`

## Report Format

Each markdown report includes:

1. **Header**: Test file name, execution time, and timestamp
2. **Summary**: Statistics table with examples, failures, warnings, and success rate
3. **Status**: Visual indicator (✅ passed, ⚠️ warnings, ❌ failed)
4. **Failed Tests**: List of failing test cases (if any)
5. **Warnings**: List of warned test cases (if any)
6. **Full Test Log**: Complete execution log in code block

## Generating Reports

The `generate-reports.sh` script processes log files and generates markdown reports:

```bash
cd tests.results
./generate-reports.sh
```

**Process**:

1. Reads all `.log` files from `logs/` directory
2. Extracts test statistics and descriptions
3. Generates formatted markdown reports (`.md`) in `reports/` directory
4. Automatically removes log files after successful report generation (full log is included in each report)
