# Test Results Directory

This directory contains test execution results and evidence for the pndcgn project.

**Location**: Repository root (`tests.results/`)

## Structure

```text
tests.results/
├── logs/              # Temporary log files (organized by date)
│   └── YYYY-MM-DD/    # Date-stamped subdirectories
│       └── {test-name}-{YYYYMMDD-HHMMSS}.log
├── reports/           # Formatted markdown test reports (organized by date)
│   └── YYYY-MM-DD/    # Date-stamped subdirectories
│       └── {test-name}-{YYYYMMDD-HHMMSS}.md
├── coverage/          # Code coverage HTML reports (organized by date)
│   └── YYYY-MM-DD/    # Date-stamped subdirectories
│       └── index.html
├── generate-reports.sh  # Script to generate reports from logs
├── reorganize-by-date.sh  # Script to reorganize existing files by date
└── README.md          # This file
```

- **Logs** (`logs/YYYY-MM-DD/`): Temporary raw test execution output from ShellSpec
  - **Organization**: Files are organized in date-stamped subdirectories (YYYY-MM-DD)
  - **Naming Convention**: `{test-file-name}-{YYYYMMDD-HHMMSS}.log`
  - **Note**: Automatically removed after report generation (full log is included in each report)
- **Reports** (`reports/YYYY-MM-DD/`): Formatted markdown test reports with summaries and full logs
  - **Organization**: Reports are organized in date-stamped subdirectories (YYYY-MM-DD)
  - **Naming Convention**: `{test-file-name}-{YYYYMMDD-HHMMSS}.md`
- **Coverage Reports** (`coverage/YYYY-MM-DD/`): Code coverage HTML reports generated by ShellSpec with kcov
  - **Organization**: Coverage reports are organized in date-stamped subdirectories (YYYY-MM-DD)
  - **Location**: `tests.results/coverage/YYYY-MM-DD/index.html`
  - **Generated**: When running `shellspec --kcov`

## Report Format

Each markdown report includes:

1. **Header**: Test file name, execution time, and timestamp
2. **Summary**: Statistics table with examples, failures, warnings, and success rate
3. **Status**: Visual indicator (✅ passed, ⚠️ warnings, ❌ failed)
4. **Failed Tests**: List of failing test cases (if any)
5. **Warnings**: List of warned test cases (if any)
6. **Full Test Log**: Complete execution log in code block

## Generating Reports

The `generate-reports.sh` script processes log files and generates markdown reports:

```bash
cd tests.results
./generate-reports.sh
```

**Process**:

1. Reads all `.log` files from `logs/YYYY-MM-DD/` date-stamped subdirectories
2. Extracts test statistics and descriptions
3. Generates formatted markdown reports (`.md`) in corresponding `reports/YYYY-MM-DD/` subdirectories
4. Also processes log files directly in `logs/` for backward compatibility

## Reorganizing Existing Files

If you have existing test results in the old flat structure, use the reorganization script:

```bash
cd tests.results
./reorganize-by-date.sh
```

This script will:
- Extract dates from existing filenames (format: `name-YYYYMMDD-HHMMSS.ext`)
- Create date-stamped subdirectories (YYYY-MM-DD) in each results directory
- Move files into appropriate date folders
- Handle coverage subdirectories specially
4. Automatically removes log files after successful report generation (full log is included in each report)
