# Codecov Setup Guide

This guide explains how to set up Codecov for the pndcgn project to track code coverage over time.

## Overview

Codecov is integrated into the GitHub Actions workflow (`.github/workflows/test-coverage.yml`) and automatically uploads coverage reports after test runs.

## Setup Steps

### 1. Sign Up for Codecov

1. Visit [Codecov.io](https://codecov.io) and sign up using your GitHub account
2. Authorize Codecov to access your GitHub repositories
3. Select the `pndcgn` repository to enable coverage tracking

### 2. Get Your Repository Upload Token

**For Public Repositories:**
- No token is required! Codecov automatically detects public repos
- Skip to step 4

**For Private Repositories:**
1. Go to your repository on Codecov: `https://codecov.io/gh/YOUR_USERNAME/pndcgn`
2. Navigate to **Settings** → **General**
3. Find the **Repository Upload Token** section
4. Copy the token (starts with `CODECOV_` or similar)

### 3. Add Token to GitHub Secrets (Private Repos Only)

1. Go to your GitHub repository: `https://github.com/YOUR_USERNAME/pndcgn`
2. Navigate to **Settings** → **Secrets and variables** → **Actions**
3. Click **New repository secret**
4. Name: `CODECOV_TOKEN`
5. Value: Paste the token from Codecov
6. Click **Add secret**

### 4. Verify Configuration

The project includes:
- ✅ `codecov.yml` - Configuration file with coverage settings
- ✅ `.github/workflows/test-coverage.yml` - Workflow that uploads coverage

### 5. Test the Integration

1. Push a commit or create a PR
2. The GitHub Actions workflow will run automatically
3. After tests complete, coverage will be uploaded to Codecov
4. Check your repository on Codecov to see the coverage report

## Configuration

### Coverage Targets

The `codecov.yml` file configures:
- **Target Coverage**: 90% (per Constitution §II)
- **Warning Threshold**: 85%
- **Status Checks**: Enabled for PRs

### Coverage File Location

Coverage reports are generated by ShellSpec/kcov:
- **Location**: `tests.results/coverage/cobertura.xml`
- **Format**: Cobertura XML (standard format for Codecov)

### Ignored Files

The following are excluded from coverage:
- Test files (`tests/**`)
- Test results (`tests.results/**`)
- Scripts (`scripts/**`)
- Documentation (`docs/**`, `specs/**`)
- Configuration files (`.md`, `.yml`, `.toml`)

## Viewing Coverage

### On Codecov Website

1. Visit: `https://codecov.io/gh/YOUR_USERNAME/pndcgn`
2. View coverage trends, file-by-file coverage, and PR coverage

### In GitHub PRs

Codecov automatically posts coverage comments on PRs showing:
- Overall coverage percentage
- Coverage changes (diff)
- File-by-file coverage
- Coverage flags (unit, integration, feature)

### Coverage Badge

Add a coverage badge to your README:

```markdown
[![codecov](https://codecov.io/gh/YOUR_USERNAME/pndcgn/branch/main/graph/badge.svg)](https://codecov.io/gh/YOUR_USERNAME/pndcgn)
```

## Troubleshooting

### Coverage Not Uploading

1. **Check workflow logs**: Look for "Upload to Codecov" step
2. **Verify file exists**: Check that `tests.results/coverage/cobertura.xml` is generated
3. **Check token** (private repos): Ensure `CODECOV_TOKEN` secret is set
4. **Check Codecov status**: Visit Codecov dashboard to see if uploads are received

### Coverage Shows 0%

This is a known limitation with kcov and sourced files. See `tests/README.md` for details on coverage tracking patterns.

### Token Issues

- **Public repos**: Token is optional, can be omitted
- **Private repos**: Token is required, must be set in GitHub Secrets
- **Invalid token**: Check token in Codecov settings and GitHub Secrets
