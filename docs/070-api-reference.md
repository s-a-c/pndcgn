## 1. Overview

### 1.1. Module Structure

**pndcgn** is organized into focused modules:

```log
bin/pndcgn                Main controller (orchestration)
src/constants.sh          ANSI color constants
src/database.sh           SQLite operations
src/processing.sh          Conversion logic
src/utilities.sh          Helper functions
```

**Module loading**:
```bash
# Source modules in order
source "${PNDCGN_ROOT}/src/constants.sh"
source "${PNDCGN_ROOT}/src/utilities.sh"
source "${PNDCGN_ROOT}/src/database.sh"
source "${PNDCGN_ROOT}/src/processing.sh"
```

### 1.2. Naming Conventions

**Function naming**:
- Prefix: `pndcgn_` (namespace)
- Module hint: `pndcgn_db_*` (database), `pndcgn_log_*` (logging)
- Verb-noun pattern: `pndcgn_compute_fingerprint`, `pndcgn_store_file`

**Variable naming**:
- Lowercase with underscores: `source_dir`, `run_id`
- Constants: Uppercase: `PNDCGN_DB`, `PNDCGN_ROOT`
- Prefix for globals: `pndcgn_*`

## 2. Main Controller (pndcgn)

### 2.1. Entry Point

#### `main()`

**Purpose**: Script entry point, orchestrates entire workflow

**Signature**:
```bash
main()
```

**Flow**:
1. Parse command-line arguments
2. Load configuration
3. Initialize database
4. Execute requested operation
5. Handle errors and cleanup

**Example**:
```bash
# Called automatically at script end
main
```

### 2.2. Initialization

#### `pndcgn_initialize()`

**Purpose**: Initialize database and verify prerequisites

**Signature**:
```bash
pndcgn_initialize()
```

**Returns**: 0 on success, non-zero on failure

**Side effects**:
- Creates database if missing
- Creates database directory
- Verifies required binaries (pandoc, sqlite3)

**Example**:
```bash
if ! pndcgn_initialize; then
    printf "Initialization failed\\n" >&2
    exit 1
fi
```

### 2.3. Configuration

#### `pndcgn_load_config()`

**Purpose**: Load configuration from TOML file and environment

**Signature**:
```bash
pndcgn_load_config()
```

**Returns**: 0 always (uses defaults on failure)

**Sets variables**:
- `pndcgn_output_type`
- `pndcgn_cache_dir`
- `pndcgn_verbose`
- `pndcgn_dry_run`

**Precedence**: CLI args > env vars > TOML > defaults

**Example**:
```bash
pndcgn_load_config
printf "Output type: %s\\n" "${pndcgn_output_type}"
```

## 3. Database Module (database.sh)

### 3.1. Connection Management

#### `pndcgn_db_init()`

**Purpose**: Initialize database schema

**Signature**:
```bash
pndcgn_db_init()
```

**Returns**: 0 on success, 1 on failure

**Side effects**:
- Creates `runs` table
- Creates `generated_pdfs` table
- Creates indexes
- Enables WAL mode

**Example**:
```bash
if pndcgn_db_init; then
    printf "Database initialized\\n"
fi
```

### 3.2. Run Operations

#### `pndcgn_db_start_run()`

**Purpose**: Insert new run record

**Signature**:
```bash
pndcgn_db_start_run <run_id> <source_dir> <target_dir> <output_type> <dry_run>
```

**Parameters**:
- `run_id` - ULID identifier (auto-generated by SQLite if not provided)
- `source_dir` - Absolute path to source
- `target_dir` - Absolute path to target
- `output_type` - Output format (pdf, epub, etc.)
- `dry_run` - 0 or 1

**Returns**: 0 on success, 1 on failure

**Example**:
```bash
# run_id is auto-generated by SQLite DEFAULT (ulid())
run_id=$(sqlite3 "${PNDCGN_CACHE_DB}" "
    INSERT INTO runs (start_time, source_dir, target_dir, output_type, status, dry_run)
    VALUES ($(date +%s), '/home/user/docs', '/home/user/output', 'pdf', 'running', 0)
    RETURNING run_id;
")
pndcgn_db_start_run "${run_id}" "/home/user/docs" "/home/user/output" "pdf" 0
```

#### `pndcgn_db_create_run()` *(Modified for Multi-Directory Support)*

**Purpose**: Create new run record with support for multiple source directories

**Signature**:
```bash
pndcgn_db_create_run <source_dirs_json> <target_root> <output_type> [dry_run]
```

**Parameters**:
- `source_dirs_json` - JSON array of source directory paths: `["/path/dir1", "/path/dir2", ...]` (replaces single `source_root` parameter)
- `target_root` - Absolute path to target output directory
- `output_type` - Output format (pdf, epub, html, etc.)
- `dry_run` (optional) - 0 or 1 (default: 0)

**Returns**: 0 on success, 1 on failure

**Stdout**: Run ID (ULID)

**Database Schema Change**:
- `runs.source_root` column now stores first element of `source_dirs` array for backward compatibility
- New `runs.source_dirs` column stores JSON array of all source directories
- For single-directory runs, `source_dirs` is single-element array: `["/path/dir"]`

**Example**:
```bash
source_dirs_json='["/home/user/docs", "/home/user/notes", "/home/user/specs"]'
run_id=$(pndcgn_db_create_run "${source_dirs_json}" "/home/user/output" "pdf" 0)
# Returns: 01ABC123DEF456...
```

**Migration Note**: For backward compatibility with existing runs, `source_root` column remains and equals first element of `source_dirs` array.

#### `pndcgn_db_finish_run()`

**Purpose**: Mark run as complete

**Signature**:
```bash
pndcgn_db_finish_run <run_id> <status> <files_total> <files_processed> <files_skipped> <files_failed>
```

**Parameters**:
- `run_id` - Run identifier
- `status` - `complete`, `failed`, `interrupted`, or `partial`
- `files_total` - Total files discovered
- `files_processed` - Files converted
- `files_skipped` - Files skipped (cached)
- `files_failed` - Files that failed

**Returns**: 0 on success, 1 on failure

**Example**:
```bash
pndcgn_db_finish_run "${run_id}" "complete" 150 10 140 0
```

### 3.3. File Operations

#### `pndcgn_db_get_fingerprint()`

**Purpose**: Look up cached file by fingerprint

**Signature**:
```bash
pndcgn_db_get_fingerprint <fingerprint> <output_type>
```

**Parameters**:
- `fingerprint` - Content fingerprint
- `output_type` - Desired output format

**Returns**: 0 if found, 1 if not found

**Stdout**: Output path if found

**Example**:
```bash
cached=$(pndcgn_db_get_fingerprint "${fingerprint}" "pdf")
if [[ -n "${cached}" && -f "${cached}" ]]; then
    printf "Cache hit: %s\\n" "${cached}"
fi
```

#### `pndcgn_db_store_file()`

**Purpose**: Store generated file metadata

**Signature**:
```bash
pndcgn_db_store_file <run_id> <source_path> <output_path> <fingerprint> <file_size> <mtime>
```

**Parameters**:
- `run_id` - Run identifier
- `source_path` - Absolute path to source
- `output_path` - Absolute path to output
- `fingerprint` - Content fingerprint
- `file_size` - Source size (bytes)
- `mtime` - Source mtime (Unix timestamp)

**Returns**: 0 on success, 1 on failure

**Example**:
```bash
pndcgn_db_store_file \
    "${run_id}" \
    "/home/user/docs/notes.md" \
    "/home/user/output/pndcgn/pdf-${run_id}/notes.pdf" \
    "12345:1699564800:a3f5b9c2d8e1f4a7b6c3d2e9f1a8b4c7" \
    12345 \
    1699564800
```

## 4. Processing Module (processing.sh)

### 4.1. File Discovery

#### `pndcgn_find_files()`

**Purpose**: Discover markdown files in directory

**Signature**:
```bash
pndcgn_find_files <directory>
```

**Parameters**:
- `directory` - Directory to search (recursively)

**Returns**: 0 always

**Stdout**: Null-terminated list of absolute paths

**Example**:
```bash
while IFS= read -r -d '' file; do
    printf "Found: %s\\n" "${file}"
done < <(pndcgn_find_files "/home/user/docs")
```

### 4.2. Conversion

#### `pndcgn_convert_file()`

**Purpose**: Convert single file using pandoc

**Signature**:
```bash
pndcgn_convert_file <source_path> <output_path> <output_type>
```

**Parameters**:
- `source_path` - Absolute path to source .md
- `output_path` - Absolute path for output
- `output_type` - Output format (pdf, epub, etc.)

**Returns**: 0 on success, 1 on failure

**Side effects**:
- Creates output directory if needed
- Invokes pandoc
- Logs conversion result

**Example**:
```bash
if pndcgn_convert_file "notes.md" "notes.pdf" "pdf"; then
    printf "Conversion successful\\n"
fi
```

### 4.3. Fingerprinting

#### `pndcgn_compute_fingerprint()`

**Purpose**: Compute content fingerprint

**Signature**:
```bash
pndcgn_compute_fingerprint <file_path>
```

**Parameters**:
- `file_path` - Path to file

**Returns**: 0 always

**Stdout**: Fingerprint string (format: `size:mtime:sha256_partial`)

**Example**:
```bash
fingerprint=$(pndcgn_compute_fingerprint "/home/user/docs/notes.md")
printf "Fingerprint: %s\\n" "${fingerprint}"
# Output: 12345:1699564800:a3f5b9c2d8e1f4a7b6c3d2e9f1a8b4c7
```

## 5. Utilities Module (utilities.sh)

### 5.1. Extension Installation

#### `pndcgn_install_ulid()`

**Purpose**: Download and install the `sqlite-ulid` extension if not already present

**Signature**:
```bash
pndcgn_install_ulid(ext_path)
```

**Parameters**:
- `ext_path`: Full path to the extension file (e.g., `./lib/ulid0.so` or `./lib/ulid0.dylib`)

**Returns**: 0 on success, 1 on error

**Behavior**:
- Checks if extension file already exists; returns immediately if found
- Detects OS and architecture
- Downloads appropriate release from GitHub
- Extracts extension to `./lib/` directory
- Prints progress messages to stdout

**Example**:
```bash
local ext_path="./lib/ulid0.so"
pndcgn_install_ulid "$ext_path"
# Downloads sqlite-ulid extension if not present
```

**Note**: ULID generation is handled by the SQLite `ulid()` function from the extension, not by Bash code. Run IDs are auto-generated using `DEFAULT (ulid())` in the database schema.

### 5.2. Path Operations

#### `pndcgn_resolve_path()`

**Purpose**: Convert to absolute path

**Signature**:
```bash
pndcgn_resolve_path <path>
```

**Parameters**:
- `path` - Relative or absolute path

**Returns**: 0 on success, 1 if path doesn't exist

**Stdout**: Absolute path

**Example**:
```bash
abs_path=$(pndcgn_resolve_path "../docs/notes.md")
printf "Absolute: %s\\n" "${abs_path}"
# Output: /home/user/docs/notes.md
```

### 5.3. Logging

#### `pndcgn_log_info()`

**Purpose**: Log informational message

**Signature**:
```bash
pndcgn_log_info <message>
```

**Parameters**:
- `message` - Message to log

**Returns**: 0 always

**Side effects**: Writes to stdout with color

**Example**:
```bash
pndcgn_log_info "Processing file: notes.md"
```

#### `pndcgn_log_error()`

### 5.4. Directory Selection

#### `pndcgn_select_source_dirs()`

**Purpose**: Select multiple source directories via fzf (or fallback to numbered list)

**Signature**:
```bash
pndcgn_select_source_dirs [max_dirs]
```

**Parameters**:
- `max_dirs` (optional) - Maximum directories selectable (default: 4)

**Returns**: 0 on selection, 1 on cancel/error

**Stdout**: Newline-separated list of selected directory paths (absolute paths)

**Side effects**:
- Launches fzf with multi-select if available
- Falls back to numbered list prompt if fzf unavailable
- Logs INFO/WARN messages to stderr
- Resolves symlinks and removes duplicates/overlaps

**Example**:
```bash
selected_dirs=$(pndcgn_select_source_dirs 5)
# Returns: /path/to/docs\n/path/to/notes\n/path/to/specs
```

**Note**: Replaces single-directory `pndcgn_select_source_dir()` function. Automatically handles deduplication, overlap detection, and symlink resolution.

#### `pndcgn_select_source_dirs_fallback()`

**Purpose**: Fallback directory selection via numbered list when fzf unavailable

**Signature**:
```bash
pndcgn_select_source_dirs_fallback <max_dirs>
```

**Parameters**:
- `max_dirs` - Maximum directories selectable

**Returns**: 0 on selection, 1 on cancel/error

**Stdout**: Newline-separated list of selected directory paths

**Side effects**:
- Displays numbered list of directories (max 50 shown)
- Reads user input from stdin
- Logs INFO/WARN for invalid input handling
- Prompts user for continue/re-prompt on invalid input

**Example**:
```bash
selected_dirs=$(pndcgn_select_source_dirs_fallback 4)
# Displays: [1] ./docs
#           [2] ./notes
#           ...
# Prompt: Enter directory numbers (comma-separated, max 4):
```

### 5.5. Prefix Computation

#### `pndcgn_compute_abbreviated_prefixes()`

**Purpose**: Compute shortest unique abbreviated prefixes for directory list

**Signature**:
```bash
pndcgn_compute_abbreviated_prefixes <dir1> [dir2] [dir3] ...
```

**Parameters**:
- `dir1`, `dir2`, ... - Directory paths (variadic, 1 or more)

**Returns**: 0 on success, 1 on error

**Stdout**: Newline-separated list of prefixes (same order as input directories)

**Algorithm**:
1. Extract basename from each directory path
2. For each basename, find shortest prefix unique among all basenames
3. If basenames identical, use parent directory name as disambiguation
4. Sanitize prefix: replace non-alphanumeric chars with hyphens

**Example**:
```bash
prefixes=$(pndcgn_compute_abbreviated_prefixes "projects/frontend" "projects/backend")
# Returns: front\nback

prefixes=$(pndcgn_compute_abbreviated_prefixes "a/docs" "b/docs")
# Returns: a-docs\nb-docs
```

#### `pndcgn_generate_prefixed_filename()`

**Purpose**: Generate prefixed output filename for multi-directory runs

**Signature**:
```bash
pndcgn_generate_prefixed_filename <prefix> <original_name> <output_type>
```

**Parameters**:
- `prefix` - Abbreviated source directory prefix (empty string for single directory)
- `original_name` - Original filename without extension
- `output_type` - Output format extension (pdf, html, epub, etc.)

**Returns**: 0 on success

**Stdout**: Formatted filename

**Format Rules**:
- Single directory (empty prefix): `{original_name}.{ext}`
- Multiple directories: `{prefix}--{original_name}.{ext}`
- Prefix separator: `--` (double hyphen)

**Example**:
```bash
filename=$(pndcgn_generate_prefixed_filename "front" "readme" "pdf")
# Returns: front--readme.pdf

filename=$(pndcgn_generate_prefixed_filename "" "readme" "pdf")
# Returns: readme.pdf (single directory, no prefix)
```

### 5.6. Configuration Parsing

#### `pndcgn_parse_toml_max_source_dirs()`

**Purpose**: Parse `max_source_dirs` setting from TOML config file

**Signature**:
```bash
pndcgn_parse_toml_max_source_dirs <config_path>
```

**Parameters**:
- `config_path` - Path to pndcgn.toml configuration file

**Returns**: 0 on success (or config missing), 1 on parse error

**Stdout**: Integer value (1-16), defaults to 4 if not configured

**Validation**:
- Values < 1 → use default (4)
- Values > 16 → cap at 16
- Non-integer values → use default (4)
- Missing `[source]` section or key → use default (4)

**Example**:
```bash
max_dirs=$(pndcgn_parse_toml_max_source_dirs "./pndcgn.toml")
# Returns: 4 (default) or configured value
```

**Note**: Logs WARN to stderr if invalid value found in config.

#### `pndcgn_validate_source_count()`

**Purpose**: Validate source directory count against configured limit

**Signature**:
```bash
pndcgn_validate_source_count <count> <limit>
```

**Parameters**:
- `count` - Number of source directories provided
- `limit` - Maximum allowed count

**Returns**: 0 if valid, 2 if exceeded

**Side effects**:
- Exits with code 2 and error message to stderr if count exceeds limit
- Error message format: "ERROR: Too many source directories (max: {limit}, got: {count})"

**Example**:
```bash
pndcgn_validate_source_count 5 4
# Exit code: 2
# Stderr: ERROR: Too many source directories (max: 4, got: 5)
```

### 5.7. Directory Utilities

#### `pndcgn_remove_overlapping_dirs()`

**Purpose**: Remove overlapping directories (subdirectories of other selected directories)

**Signature**:
```bash
pndcgn_remove_overlapping_dirs <dir1> [dir2] [dir3] ...
```

**Parameters**:
- `dir1`, `dir2`, ... - Directory paths (variadic, 1 or more, absolute paths)

**Returns**: 0 on success

**Stdout**: Newline-separated list of non-overlapping directories

**Side effects**:
- Logs INFO message to stderr for each excluded subdirectory
- Message format: "INFO: Excluding subdirectory: {subdir} (contained in {parent})"

**Algorithm**:
- For each directory, check if it's a subdirectory (path prefix match) of any other directory
- If subdirectory found, exclude it from result
- Preserves order of non-overlapping directories

**Example**:
```bash
dirs=$(pndcgn_remove_overlapping_dirs "/path/projects" "/path/projects/frontend" "/path/notes")
# Returns: /path/projects\n/path/notes
# Stderr: INFO: Excluding subdirectory: /path/projects/frontend (contained in /path/projects)
```

**Note**: Assumes all paths are absolute and symlinks already resolved.

## 6. Constants Module (constants.sh)

### 6.1. ANSI Colors

**Available constants**:
```bash
PNDCGN_RED        # Red text
PNDCGN_GREEN      # Green text
PNDCGN_YELLOW     # Yellow text
PNDCGN_BLUE       # Blue text
PNDCGN_BOLD       # Bold text
PNDCGN_RESET      # Reset formatting
```

**Usage**:
```bash
printf "%sError:%s Something went wrong\\n" "${PNDCGN_RED}" "${PNDCGN_RESET}"
```

### 6.2. Exit Codes

**Standard codes**:
```bash
0   # Success
1   # General error
2   # Invalid arguments
3   # Missing dependency
4   # Database error
5   # File operation error
```
